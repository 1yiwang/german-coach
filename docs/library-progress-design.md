# German Coach — 文库系统 · 进度激励设计

> 版本：v0.1（雏形）
> 核心原则：让"吃完 27 篇文章"变得可视化、可量化、让人想继续

---

## 一、整体结构

### 三层导航

```
首页（Dashboard）
   │   今日进度 / 当前文章 / 连击天数
   │
   ▼
📚 文库（文章列表）
   │   27 篇文章，每篇显示完成度
   │   → 点击进入
   │
   ▼
📖 精听模式（逐句通关）
   │   播放 → 复述 → 下一句
   │   记录每句播放次数
```

### 为什么分三层？

- 你不需要一次看完所有信息
- 早上打开 → 首页看一眼今天做什么
- 想继续 → 文库选文章
- 坐下开练 → 精听模式

### 按文章计数的逻辑

| 数据 | 来源 |
|------|------|
| 总文章数 | DB `documents` 表 count（27 篇） |
| 完成数 | `sentences` 里 status=completed 的文章 |
| 当前文章 | 上次学习的 `document_id` |
| 今日目标 | 你自己设的（默认 5 句）|

**不计算"今天学了多少分钟"，只算"今天过了多少句"。**

## 四、逐句精听（现有 /listen 页面的改进）

### 新增"播放计数"

```
第 8/20 句    播放第 4 次 🔄

┌──────────────────────────────┐
│      🔊 [播放]  🔄 [重播]     │
│                              │
│   👂 尝试复述这句话           │
│                              │
│   [👁️ 显示原文]              │
│                              │
│   播放 4 次后终于看原文了      │
│                              │
│  [🔍 DeepSeek 分析]          │
│  [➕ 加入复习]                │
└──────────────────────────────┘

← 上一句      → ✅ 下一句（第 12/20）
```

**"过了"的定义：** 你点击了 **"下一句"**。播放多少次才点下一句 → 记录为疲劳度。

### 疲劳度统计

| 播放次数 | 含义 |
|---------|------|
| 1-2 次 | 简单句，一次就听懂了 |
| 3-5 次 | 中等难度，需要几遍 |
| 6+ 次 | **难点句** → 自动标记为"需重点复习" |
| 直接看原文 | → 标记为"这句最难" |

这些数据汇总到首页的"本周难点 Top 3"。

## 五、从头重新开始

你说很多内容忘了想从头再来——两种模式：

```
模式 A：正常模式（默认）
  学过的句子标 ✅，跳过已完成的
  适合：每天正常推进

模式 B：重置模式
  所有句子的状态重置为"未开始"
  但保留历史统计数据（播放次数不变，只看不到了还是回到0）
  适合：你觉得"之前学的不算数，我要重来"
```

**实现方式：** `sentences` 表加一个 `attempt_count` 字段，每次重置不是删数据，而是把状态重置 + 开新 `attempt`。这样你以后还能看到"第一轮我哪句最难"。

## 六、激励系统的核心理念

| 不做 | 做 |
|------|-----|
| ❌ "你今天还没学够！" | ✅ "今天学了 5 句 🎉" |
| ❌ 强制每天必须完成 | ✅ "断了就断了，明天继续" |
| ❌ 跟别人比 | ✅ 只跟你自己比 |

**最重要的一个设计：**

> 每天的目标 = **5 句**。做完就可以收工。
> 
> 不是为了让你"偷懒"，而是为了让你的大脑每天早上都愿意打开它。
>
> "反正就 5 句，10 分钟的事。"
>
> → 打开后经常一学就是 20 句。

## 八、专注倒计时 + 随机鼓励 🕐

### 用户需求

开始学一篇文章 → 在页面固定位置显示 **1 小时倒计时**。过程中时不时弹出德语鼓励语句，每次不一样。

### 位置设计

```
┌──────────────────────────────────┐
│  📖 Lektion 3 "Im Restaurant"    │
│                     ⏱️ 42:15  ← 右上角固定  │
│                                  │
│  第 8/20 句                       │
│  ┌───────────────────────────┐   │
│  │  🔊 [播放]                │   │
│  │  👂 尝试复述这句话         │   │
│  │  [👁️ 显示原文]            │   │
│  └───────────────────────────┘   │
│                                  │
│  ─────  ⏱️  noch 42 Minuten ──── │
│       Du schaffst das! 💪        │
│       （随机鼓励，自动消失）      │
│                                  │
```

### 行为逻辑

| 时机 | 行为 |
|------|------|
| 进入 /listen（有文章 ID） | 倒计时从 60:00 开始 |
| 离开页面 | 倒计时暂停（保存剩余时间） |
| 回到页面 | 从暂停处继续 |
| 到 00:00 | 🎉 "Eine Stunde geschafft!" 彩蛋 |
| 每 5-7 分钟 | 随机德语鼓励语句弹出（2 秒后自动消失） |

### 鼓励语素材（50+ 句，避免重复）

```
"Du machst Fortschritte! Weiter so! 🌟"
"Jeder Satz zählt. 💪"
"Langsam aber sicher. 🐢"
"Gut gemacht! Schon {count} Sätze geschafft!"
"Nicht aufgeben! Gleich kommt der nächste Satz."
"Wiederholung ist der Schlüssel. 🔑"
...
```

这些句子**硬编码在代码里**就行，不需要 DeepSeek。每次从池子里随机选，不重复直到池子用完。

## 九、句子级 SRS 复习 🃏

### 用户需求

每个句子结束后，显示两个按钮：

```
✅ 我会了（Gelernt）     🔄 还需要复习（Wiederholen）
```

选了 ✅ → 句子的复习间隔拉长（像 SM-2 但简化版）
选了 🔄 → 明天/后天再回来考这句

### 与现有单词 SRS 的关系

| 维度 | 单词 SRS（已有） | 句子 SRS（新增） |
|------|----------------|----------------|
| 复习对象 | 单个词汇 | 完整句子 |
| 数据表 | `words` | `sentences`（加字段） |
| 算法 | SM-2 完整版 | **简化版**（3 级：今天/明天/3 天后） |
| 复习页面 | `/review`（已有） | 复用 /listen 或新建 /review-sentences |

### 为什么句子 SRS 用简化版？

**因为复习句子的目的是"再听一遍 + 再复述一遍"**，不是"默写单词"。

| 级别 | 下次复习 |
|------|---------|
| ✅ 我会了 | 3 天后 |
| ⚠️ 还行 | 明天 |
| 🔄 还需要复习 | **今天晚些时候再考一次** |

### 复习流程

```
1. 早上精听新文章（过新句子）
2. 每句结束时 → 选 ✅ 或 🔄
3. 选了 🔄 的句子 → 下午 /listen 页面出现 "2 句需要复习"
4. 点击 → 进入复习模式（跟精听一样，但只放声音，看你记不记得）
5. 再次选 ✅ 或 🔄
```

### 推荐先做单词 SRS 再考虑句子 SRS

你说得对——这个等句子都跑通了再做。**先精听 27 篇，积累数据，然后迭代句子 SRS 要快很多。**
